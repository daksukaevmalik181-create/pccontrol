# Скриншоты PC Control

Здесь будут размещены изображения интерфейса PC Control.

Рекомендуемые материалы:
- главный экран приложения;
- экран подключения Windows-компьютера;
- раздел управления;
- интерфейс Strix AI.

Перед публикацией убедитесь, что на скриншотах нет адресов электронной почты, токенов, QR-кодов подключения, IP-адресов и других личных данных.
