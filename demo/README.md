# Демонстрация PC Control

В этой папке будут материалы демонстрации проекта.

Можно добавить:
- короткое видео работы приложения;
- GIF с основным сценарием подключения;
- описание демонстрационного сценария.

Не добавляйте записи экрана с паролями, токенами, личными файлами или чужими компьютерами.
