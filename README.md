# PC Control

**PC Control** — проект AntiStrix Studio для удалённого взаимодействия с Windows-компьютером через Android-приложение.

Проект объединяет мобильное приложение на Flutter, Windows Agent на Python и облачную серверную часть.

> Этот репозиторий предназначен для презентации проекта и знакомства с его архитектурой. Полный исходный код и внутренние настройки находятся в приватных репозиториях.

## Что умеет проект

- Подключать Android-приложение к Windows Agent через облачную инфраструктуру.
- Предоставлять интерфейс для управления поддерживаемыми функциями компьютера.
- Работать с поддерживаемыми приложениями и мультимедийными функциями.
- Включать Strix AI — облачный AI-компонент PC Control.
- Использовать авторизацию и связанные с аккаунтом данные.

## Архитектура

```text
Android app (Flutter)
        |
        v
Backend / Relay (Render)
        |
        v
Windows Agent (Python)

Supabase — авторизация и данные аккаунта
Cloud AI — Strix AI
```

Подробнее: [Архитектура](docs/ARCHITECTURE.md).
