# Возможности PC Control

PC Control — проект для удалённого взаимодействия с Windows-компьютером через Android-приложение.

## Основные части

### Android-приложение
- Авторизация пользователя.
- Подключение к Windows Agent.
- Интерфейс управления компьютером.
- Разделы устройств и программ.
- Интеграция со Strix AI.
- Отображение баланса токенов и статуса подписки, если эти функции доступны аккаунту.

### Windows Agent
- Поддержание соединения с облачной частью.
- Получение и обработка поддерживаемых команд.
- Взаимодействие с разрешёнными приложениями и функциями Windows.

### Strix AI
- Облачный AI-чат внутри PC Control.
- Обработка запросов через серверную часть.
- Использование токенов в соответствии с настройками тарифа.

## Технологии

| Часть | Технологии |
|---|---|
| Android-приложение | Flutter / Dart |
| Windows Agent | Python |
| Backend и relay | Python, Flask и WebSocket-компоненты |
| Авторизация и данные | Supabase |
| Размещение backend | Render |
| Публичная страница проекта | Netlify |

Список отражает используемые в проекте технологии и может меняться по мере разработки.
