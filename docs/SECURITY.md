# Безопасность и границы доступа

Безопасность PC Control рассматривается как отдельная часть архитектуры.

## Основные принципы

- Пользователь должен управлять только тем компьютером, который он подключил и на использование которого имеет право.
- Серверная часть должна проверять авторизацию и принадлежность подключения аккаунту.
- Секреты и приватные ключи не должны храниться в публичном репозитории.
- Команды агента должны быть ограничены заранее определённым набором поддерживаемых действий.
- Действия, способные изменить или удалить пользовательские данные, должны требовать отдельного подтверждения.
- Загрузка файла не должна автоматически означать его запуск.

## Что не публикуется в этом репозитории

- Исходный код Android-приложения и Windows Agent.
- Серверные переменные окружения и токены.
- Ключи Supabase и Cloudflare.
- Внутренние адреса и настройки приватной инфраструктуры.
- Пользовательские данные и журналы с персональной информацией.

## Примечание для технического ревью

Этот документ описывает проектные принципы и не является независимым аудитом безопасности. Для проверки реализации специалисту можно отдельно предоставить выбранные файлы из приватного репозитория с предварительной проверкой секретов.
