# Архитектура PC Control

## Общая схема

PC Control состоит из Android-приложения, Windows-агента и облачной серверной части.

```text
Android-приложение
       |
       | защищённое подключение
       v
Облачный сервер / relay (Render)
       |
       | соединение с агентом
       v
Windows Agent на компьютере пользователя

Supabase — аутентификация и данные аккаунта.
Cloud AI — обработка запросов Strix AI.
```

## Компоненты

- **Android app (Flutter)** — интерфейс пользователя, вход в аккаунт, управление подключённым компьютером и взаимодействие со Strix AI.
- **Windows Agent (Python)** — работает на компьютере пользователя и выполняет поддерживаемые команды приложения.
- **Backend / relay** — обеспечивает облачное взаимодействие приложения и агента.
- **Supabase** — используется для аутентификации и связанных с аккаунтом данных.
- **Strix AI** — облачный AI-компонент приложения.

## Поток подключения

1. Пользователь входит в Android-приложение.
2. Приложение получает данные авторизованной сессии.
3. Windows Agent подключается к серверной части.
4. Приложение и агент обмениваются данными через облачную инфраструктуру.
5. Пользователь отправляет команду из интерфейса, а агент обрабатывает поддерживаемое действие.

Это обзорная схема. Точные протоколы, API-контракты и конфигурация серверов остаются во внутренних приватных репозиториях.
